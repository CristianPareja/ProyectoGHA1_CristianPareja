Caso de Uso CI/CD - The Zebra

Implementación de integración y entrega continua usando GitHub Actions.

¿Qué es CI/CD?

CI/CD permite automatizar procesos de integración, pruebas y despliegue de software para mejorar la calidad y velocidad del desarrollo.

Caso de uso

The Zebra es una empresa tecnológica que aplicó prácticas de CI/CD para mejorar sus procesos de desarrollo, automatizar entregas y reducir problemas al integrar cambios en el código.

GitHub Actions

En este laboratorio se usa GitHub Actions para ejecutar automáticamente un workflow cuando se suben cambios al repositorio.
